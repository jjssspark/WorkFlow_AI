# 노트북 색인

저장소 루트에 흩어져 있던 실행 노트북을 주제별로 모았다. 넘버링은 CLAUDE.md 규칙
(`01`, 하위 분류는 `01-1`)을 그대로 유지했다.

| 폴더 | 노트북 | 내용 |
|---|---|---|
| `notifications/` | `01` ~ `01-5` | 프로젝트별 알림 분리. `project_id` 도입 → 업무 딥링크 → 상태변경 행위자 표시 → 중복 알림 진단 → 병합 위험 보완 → 동시 요청 중복 차단 |
| `hybrid-rag/` | `02` ~ `02-2` | 하이브리드 RAG 검색 평가. 평가셋 구축 → dense/BM25/3-gram 검색기 비교 → RRF 융합 분석과 도입 권고 |
| `meeting-eval/` | `03` | 회의록 AI 분석 품질 베이스라인. 3단계 폴백(HuggingFace → Ollama → 규칙) 실측 |

## 실행 위치

`02`, `02-1`, `02-2`, `03`은 원래 저장소 루트에서 실행하는 것을 전제로 `Path.cwd()`를
루트로 삼았다. 폴더를 옮기면서 `App/`이 보이는 상위 디렉터리까지 거슬러 올라가 루트를
찾는 `_find_repo_root()`로 바꿨으므로, 노트북이 있는 폴더에서 그대로 실행하면 된다.

산출물 경로(`output/hybrid_rag_eval/`, `output/meeting_eval/`)는 종전대로 저장소 루트
기준이다.
