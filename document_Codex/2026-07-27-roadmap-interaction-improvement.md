# 로드맵 상호작용 개선 결과

## 반영 내용

1. 일정 막대 내부의 업무명을 제거하고, 상세 정보는 왼쪽 업무 목록과 막대 툴팁으로 확인하도록 변경했다.
2. `Shift+클릭`으로 여러 업무를 선택한 뒤 선택 업무 중 하나를 드래그하면 함께 이동하도록 구현했다.
3. `날짜순 정렬` 버튼을 추가했다. 단계와 업무 모두 시작일, 마감일, 이름 순으로 정렬하며 일정 미정 항목은 마지막에 둔다.
4. 단계 헤더·업무 행·빈 단계·빠른 추가 영역을 포함한 단계 전체를 드롭 영역으로 만들었다. 드래그 진입 시 접힌 단계도 자동으로 펼친다.
5. 주 보기에서 주차당 최소 112px을 보장하고 전체 타임라인이 화면보다 넓으면 가로 스크롤되도록 변경했다.

## 안정성 처리

- 드래그 중 상태 변경으로 업무 행 DOM이 교체되지 않도록 인라인 컴포넌트 대신 안정적인 렌더 함수를 사용했다.
- 다중 이동은 낙관적으로 화면에 반영하고 API 실패 시 이동 전 상태로 되돌린다.
- 단계 이동 후 단계별 업무 수, 완료 수, 진행률을 다시 계산한다.

## 새로고침 프로젝트 혼선 수정

- 프로젝트 컨텍스트가 준비되기 전에는 로드맵 API를 호출하지 않는다.
- `currentProjectId`가 비어 있을 때 프로젝트 `1`로 강제 폴백하던 처리를 제거했다.
- 요청 세대 번호를 사용해 프로젝트 전환 전에 시작된 요청의 늦은 응답을 무시한다.
- 새로고침 준비 단계와 프로젝트 전환 응답 역전 상황을 회귀 테스트로 추가했다.

## 로드맵 2차 개선

- 업무 행의 위·아래 절반을 드롭 지점으로 사용해 같은 단계 안에서도 순서를 바꿀 수 있다.
- 단계 헤더나 빈 영역에 놓으면 해당 단계 마지막으로 이동하며 position을 다시 저장한다.
- 서버 로드맵 응답도 상태와 무관하게 position 순서로 단계 내부 업무를 반환한다.
- 일정 막대에는 업무명 대신 담당자명 또는 `미배정`을 표시한다.
- 우측 상단에 `할 일`, `진행 중`, `막힘`, `완료` 상태 색상 범례를 추가했다.
- `프로젝트 단계 추천` 버튼은 프로젝트 기간을 다음 다섯 단계로 분할해 팝업에 제안한다.
  - 요구사항 분석
  - 기획 및 설계
  - 핵심 기능 개발
  - 통합 및 테스트
  - 결과물 및 발표 준비
- 팝업에서 단계명과 시작일·마감일을 수정하고 행을 추가하거나 삭제한 다음 생성할 수 있다.
- 같은 이름의 추천 단계가 이미 있으면 해당 단계는 중복 생성하지 않는다.
- `날짜순 정렬`은 정렬된 업무의 position을 서버에 저장해 새로고침 후에도 유지한다.

2차 검증 그래프는 `output/roadmap/roadmap-secondary-improvement-validation.svg`에 저장했다.

## 단계 삭제 및 업무 보존

- 팀장에게 각 단계의 삭제 버튼을 제공한다.
- 삭제 확인창에서 해당 단계의 업무 개수와 `단계 미지정` 이동 동작을 안내한다.
- 삭제 API는 연결 업무의 `milestoneId`를 먼저 비운 뒤 단계만 삭제한다.
- 화면에서도 삭제 즉시 기존 업무를 `단계 미지정` 영역으로 옮기며, API 실패 시 이전 상태로 복구한다.
- 프론트엔드 로드맵 테스트 24개와 백엔드 `RoadmapServiceTest`, Vite 빌드가 통과했다.

삭제 검증 그래프는 `output/roadmap/roadmap-stage-deletion-validation.svg`에 저장했다.

## 로드맵 간소화·정렬 고정·호버 상세

- 단계 아래의 `업무 바로 추가` 버튼과 인라인 입력 영역을 제거했다.
- `날짜순 정렬`을 프로젝트별 고정 보기 설정으로 브라우저에 저장한다.
- 로드맵 화면을 벗어났다가 돌아오거나 데이터를 다시 조회해도 시작일·마감일 순서가 자동 적용된다.
- 로드맵 API 응답에 업무 설명을 포함했다.
- 일정 막대에 커서를 올리면 업무명, 담당자, 상태, 기간, 상세 설명을 카드로 표시한다.
- 체크리스트는 최초 호버 시 불러와 완료율과 최대 5개 항목을 표시하고 이후에는 캐시를 사용한다.
- 프론트엔드 로드맵 테스트 25개, 백엔드 `RoadmapServiceTest`, Vite 빌드가 통과했다.

검증 그래프는 `output/roadmap/roadmap-hover-and-sort-validation.svg`에 저장했다.

## 마일스톤 막대 시인성

- 마일스톤 막대는 전체 단계 기간을 나타내는 연한 트랙과 완료 비율을 나타내는 파란 채움으로 구성된다.
- 진행률 채움 자체에 `rounded-full`을 적용해 100% 미만일 때도 양끝이 둥글게 표시된다.
- 단계명 영역을 왼쪽에 고정해 가로 스크롤 중에도 단계 번호, 이름, 기간, 진행률과 삭제 버튼을 확인할 수 있다.
- 막대 접근성 이름과 툴팁에 단계명, 기간, 진행률을 포함했다.
- 로드맵 컴포넌트 테스트 11개와 Vite 프로덕션 빌드가 통과했다.
